# MacTahoe icon theme (third party)

`MacTahoe-icons.tar.xz` contains the **MacTahoe** and **MacTahoe-dark** icon themes by **Vince Liuice**
(https://github.com/vinceliuice/MacTahoe-icon-theme, based on WhiteSur), redistributed unmodified in SVG source form.

**License: GPL-3.0** (see `COPYING.MacTahoe`, authors in `AUTHORS.MacTahoe`). It is *not* covered by this repository's MIT license.
`tahoe-dolphin-setup` unpacks it into `~/.local/share/icons` only if the theme is not already installed.
